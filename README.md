# TodoList | 할 일 리스트

<img width="684" height="589" alt="image" src="https://github.com/user-attachments/assets/e2b79a79-91c3-4f22-a6f6-99bc10df292e" />

**설명**

 메인 화면에서 할 일들을 리스트로 정리하고, 볼 수 있다.

**기능**

1. 입력 창에 내용을 입력한다.
2. 추가 버튼을 클릭한다.
3. 리스트에 내용을 표시 한다.
4. 완료 시 체크 여부를 저장한다.
5. 삭제 버튼을 눌러 삭제한다.

**LocalStorage**

브라우저에 유저가 입력한 내용을 저장하고, 

새로고침 한 뒤에 저장된 데이터를 다시 불러온다.

**사용된 언어**

HTML / CSS / JavaScript
